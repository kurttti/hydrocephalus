# Tools

Здесь будут воспроизводимые CLI-утилиты для задач, не принадлежащих пользовательскому интерфейсу:

- проверка DICOM и отчёт о метаданных без PHI;
- деидентификация и аудит результата;
- сбор dataset manifest;
- проверка model package и checksums;
- сравнение ONNX с исходной моделью;
- генерация синтетических фикстур;
- сбор release diagnostics с редактированием чувствительных полей.

Каждая утилита должна поддерживать `--help`, машинно-читаемый код возврата, dry-run для изменяющих операций и тесты на ошибочные входы. Никакие инструменты не должны автоматически загружать исследования в сеть.

## Что уже есть

| Утилита | Назначение |
|---|---|
| `Hydrocephalus.Inventory` | инвентаризация выборки: агрегаты по пациентам, исследованиям, сериям и замечаниям |
| `Hydrocephalus.ReviewPlan` | план ручной рецензии; запускает только владелец данных |
| `Hydrocephalus.BatchMeasure` | пакетный замер выборки конвейером приложения |

### `Hydrocephalus.BatchMeasure`

```
Hydrocephalus.BatchMeasure --out <каталог вне репозитория> [--dry-run] <источник> [<источник>...]
```

- **Каждое исследование проходит через `AnalyzeStudyUseCase.ExecuteAsync`** — тот же путь,
  который создаёт рабочую копию и уничтожает её в `finally`. Отдельный цикл
  «импортировать и измерить» стал бы единственным местом, где рабочая копия
  переживает сбой (ADR 0006).
- **Вывод — клинический набор данных**: измерения, привязанные к псевдонимам. Он пишется
  только в `--out`, и утилита отказывается работать, если этот каталог лежит внутри
  репозитория. В каталог уходят `results.jsonl`, канонические отчёты и журнал аудита прогона.
- **В консоль уходят только агрегаты**: исходы с причинами отказа, исключения по типу,
  число измерений и их достоверность, коды замечаний, время. Ни путей, ни псевдонимов,
  ни значений.
- **Исключённая владельцем данных папка `Головы` отклоняется** до разбора.
- **Одно исследование замеряется один раз**, даже если лежит в нескольких источниках:
  берётся экземпляр с наибольшим числом срезов.
- Исключение по исследованию не останавливает прогон; сохраняется его тип, а не текст —
  в тексте путь к источнику с фамилией пациента.
- Прогон ведётся от имени исследователя: сбор измерений по выборке — работа с выборкой,
  а не лечебная. В CI утилита собирается, но не запускается.
