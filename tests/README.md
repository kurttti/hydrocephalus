# Тестирование

## Пирамида

- **Unit:** доменные инварианты, геометрия, признаки, схемы и коды ошибок.
- **Contract:** DICOM/NIfTI адаптеры, model package и формат отчёта.
- **Integration:** импорт → QC → инференс → отчёт на синтетическом наборе.
- **Golden:** стабильность измерений и оверлеев на разрешённом эталонном наборе.
- **UI:** критические сценарии WPF, отмена, доступность и отказные состояния.
- **Security:** злонамеренные/повреждённые файлы, PHI в логах, подпись модели.
- **Clinical validation:** отдельный замороженный протокол вне обычного CI.

Тестовые фикстуры должны быть синтетическими или явно разрешёнными. Для каждого golden-файла хранится источник, лицензия, ожидаемый результат и причина допустимости публикации.

CI не загружает приватные медицинские данные и не отправляет их во внешние сервисы.

## Проверка геометрии

Геометрия проверяется на синтетических сериях с заранее известным ответом: шаг между срезами измеряется по `ImagePositionPatient` вдоль нормали среза, поэтому в наборе есть косая и корональная серии — на них разность координат Z дала бы неверный шаг. Отдельно закреплены пропущенный срез, совпадающие положения, зазор между срезами и произвольный порядок файлов в каталоге.

Проверка на разрешённых публичных данных пока не выполняется: для неё нужен manifest с источником, лицензией, ожидаемым результатом и обоснованием допустимости публикации каждого файла. До появления такого manifest покрытие ограничено синтетикой, и это ограничение, а не готовность.
