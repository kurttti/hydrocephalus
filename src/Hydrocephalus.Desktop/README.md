# Hydrocephalus.Desktop

WPF-клиент и composition root приложения.

## Здесь будут

- окна, страницы, ViewModel и команды;
- мультипланарный просмотр МРТ и оверлеев;
- локализация, доступность и отображение прогресса;
- визуализация признаков, вероятностей, неопределённости и отказов QC;
- подключение реализаций через dependency injection.

## Ограничения

UI не вычисляет медицинские признаки, не читает DICOM напрямую и не содержит пороги модели. ViewModel обращаются только к use case-интерфейсам `Application`.

## Первые тесты

- импорт и отмена анализа;
- блокировка экспорта при незавершённом QC;
- корректное отображение неизвестного/отказного результата;
- масштабирование и клавиатурная навигация;
- отсутствие PHI в сообщениях об ошибке.
