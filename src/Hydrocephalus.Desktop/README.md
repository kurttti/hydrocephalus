# Hydrocephalus.Desktop

WPF-клиент и composition root приложения.

## Здесь будут

- окна, страницы, ViewModel и команды;
- мультипланарный просмотр МРТ и оверлеев;
- локализация, доступность и отображение прогресса;
- визуализация признаков, вероятностей, неопределённости и отказов QC;
- подключение реализаций через dependency injection.

## Ограничения

UI не вычисляет медицинские признаки, не читает DICOM напрямую и не содержит пороги модели. ViewModel обращаются только к use case-интерфейсам `Application`.

## Первые тесты

- импорт и отмена анализа;
- блокировка экспорта при незавершённом QC;
- корректное отображение неизвестного/отказного результата;
- масштабирование и клавиатурная навигация;
- отсутствие PHI в сообщениях об ошибке.

## Состояние

Собран composition root (`Composition/`): соль псевдонимизации, импорт с деидентификацией, входной контроль качества, хранилище отчётов и журнал аудита связываются в сценарий анализа. Приложение запускается и проходит сценарий целиком.

Связывание сделано конструкторами вручную, без контейнера: объектов пять, и контейнер добавил бы зависимость и косвенность, ничего не упростив. Он появится вместе с ViewModel, у которых есть собственный жизненный цикл.

Экрана просмотра пока нет. По ADR 0007 плоскости строятся из объёма, приведённого к изотропной сетке, — того же, на котором считаются признаки. Ресэмплинг относится к M3, и рендерер поверх анизотропного объёма показывал бы врачу не то, что измеряет модель.
