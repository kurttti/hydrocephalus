# Hydrocephalus.Infrastructure

Адаптеры внешнего мира.

## Планируемые модули

- чтение DICOM/NIfTI и преобразование координат;
- карантин, деидентификация и безопасный временный каталог;
- локальное зашифрованное хранение;
- экспорт отчёта;
- структурированный audit log без PHI;
- позднее — PACS/DICOMweb за отдельными интерфейсами.

Инфраструктурный слой не выбирает диагноз и не интерпретирует вероятность модели. Любая библиотека изолируется адаптером и контрактными тестами на геометрию, кодировки и ошибочные входы.
