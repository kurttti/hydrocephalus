# Hydrocephalus.Inference

Локальный воспроизводимый конвейер анализа изображения.

## Этапы

1. проверка model package и совместимости;
2. QC/OOD входа;
3. ориентация, ресэмплинг и нормализация;
4. ONNX-сегментация;
5. постобработка масок и геометрический QC;
6. вычисление признаков;
7. калиброванная классификация;
8. формирование объяснения и provenance.

## Требования

- одинаковый вход и package дают одинаковый результат в пределах документированного допуска;
- CPU-путь покрывается интеграционными тестами;
- GPU-путь сравнивается с CPU на эталонном наборе;
- любой этап возвращает типизированную ошибку/отказ, а не частичный диагноз;
- предобработка соответствует конфигурации, использованной при обучении.

## Состояние

Реализован входной контроль качества по геометрии и метаданным (`QualityControl/`): непротиворечивость геометрии, поддерживаемый размер вокселя, поле обзора, уровень входа и отсечение постконтрастных серий.

Проверки, которым нужны воксели — двигательные артефакты, фактическое обрезание головы полем обзора и выход за пределы обучающего распределения, — требуют загруженного объёма и model package и появятся вместе с ними (M4). Поэтому пройденный входной контроль сейчас означает «геометрия пригодна», а не «изображение проверено целиком».

`IInferenceEngine` пока не реализован: контракт возвращает прогноз с версиями модели, а model package появляется в M4.
