# ML workspace

Исследовательский контур обучения и экспорта моделей. Он не поставляется пользователю как часть Windows-клиента.

## Планируемая структура

```text
ml/
├── configs/          # версионированные параметры экспериментов
├── src/
│   ├── data/         # manifests и transforms
│   ├── segmentation/ # обучение сегментации
│   ├── features/     # измеримые признаки
│   ├── classification/
│   ├── evaluation/
│   └── export/
├── tests/
└── model_cards/
```

Папки создаются вместе с первым исполняемым модулем, чтобы пустая структура не маскировала отсутствие реализации.

## Правила

- конфигурация является частью результата эксперимента;
- доступ к данным идёт через manifest, а не жёстко заданные пути;
- notebook не является production-пайплайном;
- экспорт ONNX проверяется на численное соответствие исходной модели;
- model card обязательна для любого кандидата, передаваемого в приложение;
- веса и данные не коммитятся в git.

Методические требования: [docs/ml/README.md](../docs/ml/README.md), критерии оценки: [docs/validation/README.md](../docs/validation/README.md).
