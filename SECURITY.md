# Безопасность

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости или примеры с медицинскими данными в открытой issue. Свяжитесь с владельцем репозитория приватным каналом GitHub Security Advisories. Контактный процесс необходимо настроить до первой пилотной поставки.

## Границы данных

- обработка медицинских изображений локальна по умолчанию;
- сетевые интеграции отключены до явной настройки администратором;
- рабочие копии деидентифицируются, шифруются и удаляются по политике хранения;
- журналы содержат технические идентификаторы корреляции, но не PHI;
- модель, конфигурация и отчёт должны иметь проверяемые хеши и версии;
- установщик и обновления должны быть подписаны.

Подробная модель угроз описана в [docs/security/README.md](docs/security/README.md).
