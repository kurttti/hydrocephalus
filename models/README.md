# Model artifacts

Git хранит только схемы, model cards, manifests и checksums. Обученные веса и готовые model packages публикуются в отдельном контролируемом хранилище или GitHub Release после проверки размера, лицензии, приватности и экспортных ограничений.

Каждый пакет должен содержать:

- уникальную версию и commit обучения;
- dataset manifest ID;
- поддерживаемые входы и классы;
- метрики внутренней и внешней валидации;
- известные ограничения и противопоказанные сценарии;
- параметры QC/OOD и калибровки;
- совместимость с приложением;
- криптографические хеши и подпись.

Неподписанный, несовместимый или неполный пакет приложение отклоняет.
