## Правило источника истины

- клиническое назначение и противопоказания меняются через клинический review;
- формат model package определяется в `docs/ml`;
- интерфейсы компонентов определяются в `docs/architecture`;
- критерии допуска модели определяются в `docs/validation`;
- локальные README компонентов не должны противоречить этим документам.
