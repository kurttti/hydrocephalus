# Валидация

## Уровни доказательности

| Уровень | Назначение | Результат |
|---|---|---|
| Технический | корректность импорта, геометрии, предобработки и экспорта | тестовый отчёт |
| Внутренний | разработка на данных одного/нескольких центров с patient-level split | исследовательская модель |
| Внешний | замороженная модель на независимом центре/протоколе | кандидат пилота |
| Проспективный многоцентровый | новые пациенты и реальный рабочий процесс | основание для оценки клинического применения |

Внутренняя перекрёстная проверка не заменяет внешнюю валидацию.

## Минимальные метрики

Классификация:

- ROC AUC и PR AUC с 95% доверительными интервалами;
- чувствительность, специфичность, PPV, NPV и balanced accuracy при заранее выбранном пороге;
- матрица ошибок для многоклассовой задачи;
- Brier score, calibration intercept/slope и график калибровки;
- доля отказов QC/OOD и метрики на оставшейся выборке.

Сегментация и измерения:

- Dice и Hausdorff distance для масок;
- ICC и Bland–Altman для численных измерений;
- MAE для углов, индексов и объёмов;
- частота клинически значимых грубых ошибок.

## Обязательные подгруппы

Отдельно проверяются центры, производители/сканеры, напряжённость поля, возраст и пол, DESH-положительные и DESH-отрицательные случаи, болезнь Альцгеймера, сосудистые изменения, заместительная гидроцефалия и смешанные формы.

## Критерии допуска к пилоту

Численные пороги утверждает клиническая и статистическая команда до открытия тестовой выборки. Помимо метрик кандидат должен:

- пройти внешний тест без переобучения;
- иметь приемлемую калибровку и рабочий механизм отказа;
- показывать врачу проверяемые маски и признаки;
- документировать ошибочные случаи и ограничения;
- иметь замороженный model package, model card и полный audit trail;
- пройти privacy, security и usability review.

## Отчётность

План разработки и публикация ориентируются на CLAIM и TRIPOD; риск систематической ошибки и применимость оцениваются с использованием PROBAST. Эти чек-листы не заменяют регуляторную оценку и клиническое исследование.
