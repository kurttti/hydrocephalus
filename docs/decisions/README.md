# Журнал решений

Архитектурные решения (ADR) добавляются отдельными Markdown-файлами по шаблону `NNNN-краткое-название.md`.

## Шаблон

```markdown
# ADR NNNN: Название

- Статус: proposed | accepted | superseded
- Дата: YYYY-MM-DD
- Владельцы: роли/команда

## Контекст
## Решение
## Рассмотренные варианты
## Последствия и риски
## План проверки
```

## Первые ADR

1. WPF и поддерживаемая версия .NET LTS.
2. In-process ONNX или изолированный локальный worker.
3. DICOM-библиотека и профиль деидентификации.
4. Формат model package и подпись.
5. Формат структурированного отчёта.
6. Локальное шифрование и политика удаления.
