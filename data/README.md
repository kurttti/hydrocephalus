# Data boundary

Эта папка не предназначена для реальных медицинских данных.

Разрешены:

- JSON Schema и словари данных;
- manifests без PHI;
- синтетические DICOM/NIfTI, созданные специально для тестов;
- ссылки и скрипты получения публичных наборов при совместимой лицензии.

Запрещены исходные и производные данные пациентов, скриншоты PACS, таблицы соответствия идентификаторов и выгрузки метаданных. `.gitignore` блокирует распространённые медицинские форматы, но не заменяет ручную проверку перед commit.

Политика данных: [docs/data/README.md](../docs/data/README.md).
